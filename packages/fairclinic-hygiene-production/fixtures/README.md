# Fairclinic Hygiene Production fixtures

Everything here is fictional: the practice, hygienists (Hana Test, Iris Demo, Jo Temp) and fees. 2 to 6 November 2026. No patient data.

- `settings.json`: target 150 per hour, 15% open time. `settings-typo.json` has a misspelt key.
