# Real-data tests (2026-11-19)

Made by `node scripts/realdata.mjs` (`npm run realdata`; `--download` first). Public files only, in the format their publisher puts out; nothing private, nothing sent to any model (masking off, local run). The downloaded files are kept in `_realdata/`, which is git-ignored. Each agent result was recounted with separate code in the same script.

| Source | Agent | What ran | What it found | Wrong findings | Changed in this pass |
